## Decisions and verified starting state

### Agreed decisions

- The destination is the public GitHub user repository `adampisula/modmidi`; the user will create it.
- Old repository histories do not need to be preserved. The old `modmidi` organization repositories should be archived read-only after migration, where the user has the necessary access.
- `MIDIUSB` remains a separate repository, outside this monorepo, in a sibling directory. Its intended upstream URL is `https://github.com/adampisula/MIDIUSB.git`.
- Keep `modmidi-arduino/` at the monorepo root, parallel to `boards/`.
- All three boards use an STM32F103C8 and Arduino framework. MM00's schematic indicates a 16 MHz HSE; verify clock configuration rather than assuming the common 8 MHz board default.
- **Do not add board firmware in this migration.** Adam will add firmware later. Provide PlatformIO project configuration and instructions, but be explicit that a board firmware build cannot succeed until source firmware is added.
- EX08 is passive and has no MCU, so it gets no `software/` directory or PlatformIO project.
- Use `boards/<BOARD>/hardware/output/` for manually generated PDFs and, if desired, Gerbers and BOMs. The user generates these; required board PDFs should be committed and linked from the board README. Keep output files out of ignore rules.
- README scope: English root README; one README for each board; one for `modmidi-arduino`. No READMEs in `hardware/` or `software/`; do not change MIDIUSB's README.
- MIT was selected for first-party monorepo work, including original hardware, with `Copyright (c) 2025 Adam Pisula`. Third-party dependencies/assets retain their own licenses; do not claim them as MIT. MIDIUSB is LGPL-2.1, USBLibrarySTM32 is LGPL-3.0-or-later, and the bundled E-Switch STEP/footprint assets have no accompanying license information. Verify the model's redistribution terms before public push.
- Board projects will reference the local library with `symlink://../../../modmidi-arduino`. Document the local-path setup. `library.json` already points its repository URL at the intended monorepo.
- The public `adampisula/MIDIUSB` branch `1.0.5` is verified and matches the pinned `#1.0.5` dependency; it has no `1.0.5` tag. The fork adds STM32-specific source changes and retains LGPL-2.1.

### Starting state recorded during repository inspection

- The workspace root is not currently a Git repository. `EX08/`, `MM00/`, `MM01/`, `modmidi-arduino/`, and `MIDIUSB/` are separate nested Git repositories.
- The board repositories contain hardware KiCad files only; no PDFs or firmware were found. No PlatformIO project configuration was found.
- `modmidi-arduino/` contains `library.json`, public headers under `include/`, and sources under `src/`. Read those files before writing its API documentation.
- The board hardware ignore files currently ignore missing-3D-model reports, KiCad cache/backups, JLCPCB outputs, and BOMs; MM00 and EX08 also ignore `*.lck`. Consolidate these rules at the root and retain local ignore files unless there is a verified reason to remove them.
- MM00 uses KiCad 9.0 file format; MM01 and EX08 use KiCad 8.0. KiCad 9.x is the minimum version that opens all projects. MM01 has a non-standard `SW-Eswitch:TL1105` footprint whose availability/embedding must be checked.
- No README was found outside MIDIUSB, and no monorepo root license exists. MIDIUSB has its own `README.adoc` and `LICENSE.txt`; leave them in its separate repository.
